# Система управления банковскими картами

## Описание
Приложение для управления банковскими картами:
- Создавать банковские карты.
- Пополнять карты и переводить средствв между ними
- Администратору доступно управление пользователями и расширенное управление картами

#### Схема REST API приложения в формате OpenAPI находится в папке docs и автоматически обновляется при изменении контроллеров и сущностей

## Технические требования
Перед началом разработки установите:
- Java 17
- Docker
- Docker Compose
- Maven

Также создайте и настройте переменные окружения:
- `ENCRYPTION_SECRET_KEY`: секрет для шифрования номеров карт (длина 256 байт, закодированный в Base64).
- `ENCRYPTION_HASH_PEPPER`: для расчета уникального хэша номеров карт (длина 32 байта, закодированный в Base64).
- `JWT_SECRET`: секрет для JWT (длина 32 байта, закодированный в Base64).
- `POSTGRE_BANKCARDS_DB_NAME`, `POSTGRE_BANKCARDS_USER`, `POSTGRE_BANKCARDS_PASS`: данные для PostgreSQL.
- `FRONTEND_URL`: URL (или список URL) фронтенд-приложения, которому разрешено делать запросы 

## Сборка и запуск

### Сборка приложения
```bash
./mvn package
```
### Тестирование

 Чтобы запустить тесты, выполните стандартную задачу Maven:
```bash
./mvn test
```

### Запуск для разработки
1. Запустите необходимые контейнеры:
    ```bash
    ./docker-compose up
    ```
